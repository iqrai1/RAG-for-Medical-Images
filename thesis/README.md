# Thesis PDF

`Thesis.pdf` is not included in this initial commit (it's 31.9MB and exceeded
the download connector used to assemble this repo).

To add it:

```bash
cp /path/to/Thesis.pdf thesis/Thesis.pdf
git add thesis/Thesis.pdf
git commit -m "Add thesis PDF"
git push
```

Once added, update the link in the root [README.md](../README.md) (it already
points to `thesis/Thesis.pdf`, so no other changes are needed).
